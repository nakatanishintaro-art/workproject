# 業種別応用コース — 建設業／製造業／サービス業

基礎コース（全12回）修了者が、**自分の職務に直結する使い方**を身につけるための応用編。
各回はやはり **1回60分＝1テーマ**、ハンズオン中心。業務の実データではなく**サンプルデータ**で練習し、
本番導入はセンターのAIエージェント導入フェーズで行います（＝研修と導入がつながる設計）。

> 助成金の観点：業種別応用は「職務に関連した訓練（DX化に必要な知識・技能）」に明確に該当し、
> 訓練時間を積み増して上位プラン（スタンダード／プレミアム）へ拡張する中核になります。

各回の共通フォーマット：**到達目標／進行（60分）／演習／成果物（証憑）／注意点**。標準タイムテーブルは基礎コースと同じ（`講師運営ガイド.md`）。

---

## A. 建設業 応用（全4回）

### 建-1　現場写真の整理と報告書ドラフト
- **到達目標**：撮影メモや工程情報から、日報・報告書の下書きをAIに作らせられる。
- **進行**：解説（写真＋メモ→文章化の流れ）→ サンプルの現場メモから報告書ドラフト作成 → 手直し。
- **演習**：「本日の作業内容メモ」から作業報告書を1件作成。
- **成果物**：報告書ドラフト1件。
- **注意**：現場名・施主名など実名は入れない（サンプル名で練習）。

### 建-2　安全書類・提出書類の作成補助
- **到達目標**：定型の安全書類・届出文の文面をAIで下書きし、記載漏れを確認できる。
- **進行**：書類の型をAIに覚えさせる指示 → 項目の抜け漏れチェックの依頼 → 修正。
- **演習**：サンプル様式の下書き＋「不足項目はある？」の確認。
- **成果物**：書類ドラフト＋チェック結果。
- **注意**：最終確認は必ず人が行う（法定書類の正確性はAI任せにしない）。

### 建-3　過去見積からの積算アシスト
- **到達目標**：類似案件の情報から、見積の初動（項目出し・概算の考え方）を素早く作れる。
- **進行**：積算の考え方を整理させる → 項目の抜けを洗い出す → 概算表のたたき台作成。
- **演習**：サンプル案件で見積項目リストと概算表のたたき台を作成。
- **成果物**：見積たたき台（項目リスト＋概算表）。
- **注意**：金額は必ず自社基準で検算。AIの数字を鵜呑みにしない。

### 建-4　日報・週報・現場連絡の効率化
- **到達目標**：日々の連絡・日報・週報のテンプレ化と自動下書きができる。
- **進行**：日報テンプレ設計 → 箇条書きメモから清書 → 週次サマリー化。
- **演習**：1週間分のサンプルメモから週報を1本作成。
- **成果物**：日報テンプレ＋週報1本。

## B. 製造業 応用（全4回）

### 製-1　生産日報・検査記録の整理と集計
- **到達目標**：手書き/入力データを整え、集計・簡単なレポートにできる。
- **進行**：記録の整形指示 → 集計表化 → 気づき（傾向）の要約。
- **演習**：サンプル日報データを集計表にし、要点を3行で要約。
- **成果物**：集計表＋要約。
- **注意**：数値は検算。品質・安全に関わる判断は人が行う。

### 製-2　作業手順マニュアルをAIに聞く（多能工化）
- **到達目標**：手順書をもとに「この工程どうやる？」へ即答できる状態をイメージできる。
- **進行**：手順書をAIに読ませ、質問に答えさせる → 新人向けにやさしく言い換え。
- **演習**：サンプル手順書から「新人向けQ&A」を5問作成。
- **成果物**：新人向けQ&A集。
- **注意**：安全上重要な手順は原本（正規マニュアル）を必ず参照。

### 製-3　不良・トラブル報告の要約と分類
- **到達目標**：報告文を要約・分類し、共有と一次分析を効率化できる。
- **進行**：報告の要約指示 → 種類別に分類 → 「考えられる原因」の観点出し。
- **演習**：サンプル不良報告を要約・分類し、確認すべき観点を列挙。
- **成果物**：要約・分類表。
- **注意**：原因の断定はしない。あくまで人の分析の補助。

### 製-4　改善提案・5S・ヒヤリハットのアイデア出し
- **到達目標**：現場改善のアイデア出しと提案文づくりにAIを使える。
- **進行**：課題からアイデア出し → 実行しやすさで整理 → 提案書のたたき台。
- **演習**：サンプル課題で改善アイデア10個＋提案書たたき台。
- **成果物**：改善提案書（たたき台）。

## C. サービス業 応用（全4回）

### サ-1　問い合わせ・FAQ対応
- **到達目標**：よくある質問への回答文を整え、一次対応の下書きを作れる。
- **進行**：FAQの回答文作成 → 言い回しの統一（丁寧・簡潔）→ 想定問答の拡張。
- **演習**：サンプルの問い合わせ5件に対する回答文を作成。
- **成果物**：FAQ回答テンプレ集。
- **注意**：料金・在庫・予約可否など変動情報は最新の実情報で確認。

### サ-2　口コミ・レビュー返信文の作成
- **到達目標**：良い口コミ・厳しい口コミそれぞれに、適切な返信文を作れる。
- **進行**：口コミの内容に応じた返信の型 → 感謝／お詫び／改善の伝え方 → トーン調整。
- **演習**：サンプル口コミ（高評価・低評価）へ返信文を各1本。
- **成果物**：口コミ返信テンプレ（高評価用・低評価用）。
- **注意**：個人を特定する情報は書かない。感情的にならない定型を持つ。

### サ-3　予約・シフト・事務作業の補助
- **到達目標**：予約情報の整理やシフト案づくりの補助にAIを使える。
- **進行**：予約情報の整形・一覧化 → 条件を伝えてシフト案のたたき台 → 確認。
- **演習**：サンプル予約データを一覧化し、簡単なシフト案を作成。
- **成果物**：予約一覧＋シフトたたき台。
- **注意**：最終調整は人が実施（労務・公平性の判断はAI任せにしない）。

### サ-4　販促・SNS・お知らせ文の作成
- **到達目標**：販促文・SNS投稿・お知らせの文面を素早く量産・調整できる。
- **進行**：投稿文の型 → キャンペーン告知やお知らせを複数案 → ターゲット別に調整。
- **演習**：サンプルの催事について、SNS投稿3案＋お知らせ文1本。
- **成果物**：SNS投稿案＋お知らせ文。

## プラン別の組み合わせ例（時間の積み上げ）

| プラン | 構成例 | 合計時間の目安 |
|--------|--------|--------------|
| ライト | 基礎12回（＋業種別から2〜3回） | 12〜15時間 |
| スタンダード | 基礎12回＋業種別全4回＋反復演習・個別実務適用の回を追加 | 100時間前後 |
| プレミアム | 上記＋部門横断・複数業務・エージェント運用研修・現場OJT連携を追加 | 200時間以上 |

> スタンダード／プレミアムでは、同じテーマを**繰り返し演習**する回や、**各自の実務に当てはめる個別回**を追加して時間を積み上げます（詰め込みすぎない設計を維持）。詳細な時間割は受講者の人数・レベルに合わせて `講師運営ガイド.md` に沿って個別設計します。
