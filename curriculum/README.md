# 研修カリキュラム（AI未経験者向け）

山口県AI・DX人材育成センターの研修カリキュラム。**「AIを一度も使ったことがない人」**を対象に、
**1回＝1時間＝1テーマ**で無理なく進められるよう設計しています。

## この教材の構成

| ファイル | 内容 | 使う場面 |
|---------|------|---------|
| `基礎コース_全12回.md` | AI未経験者向けの共通カリキュラム（全12回・12時間）。回ごとに進行台本・演習・成果物まで記載 | すべての受講者の入口。まずここから |
| `業種別応用コース.md` | 建設業・製造業・サービス業ごとの実務応用（各業種3〜4回） | 基礎修了後、職務に直結させる |
| `スタンダード100時間カリキュラム.md` | 未経験→実務活用→エージェント運用まで、**全100回（1回1時間）＝ちょうど100時間**のテーマ・内容一覧（12フェーズ） | スタンダードプラン（助成金100〜200時間区分）の設計図 |
| `講師運営ガイド.md` | 標準タイムテーブル・準備物・つまずき対処・宿題・助成金の証憑管理 | 講師が研修を運営するとき |

## 設計方針（AI未経験者のために）

1. **不安をとる → まず触る → 仕事に当てはめる → 自動化（エージェント）へ** の順で段階設計。
2. **座学は最小限、毎回ハンズオン中心**。「聞く」より「自分で1回やる」を優先。
3. 例題はすべて**身近な業務**（メール・報告書・問い合わせ等）から選ぶ。専門用語は都度かみ砕く。
4. **1回で1つだけ**新しいことを扱う。詰め込まない。
5. 毎回**小さな成果物**を残す（達成感＋助成金の証憑になる）。

## 標準の進め方（1時間の型）

| 時間 | 内容 |
|------|------|
| 0–5分 | 前回の振り返り／今日のゴール共有 |
| 5–20分 | テーマ解説（**デモ中心**、座学は短く） |
| 20–50分 | **ハンズオン演習**（各自が実際に触る／講師が巡回サポート） |
| 50–58分 | 成果の共有・質疑 |
| 58–60分 | まとめ・宿題（任意）・次回予告 |

## 料金プラン・助成金との対応

- **基礎コース全12回（12時間）** だけで、人材開発支援助成金（事業展開等リスキリング支援コース）の
  **「訓練時間10時間以上」**要件を満たします（＝ライトプランの下限をクリア）。
- 基礎＋業種別応用を積み上げれば、スタンダード（100時間前後）・プレミアム（200時間以上）へ拡張できます。
- 助成の要件は **①10時間以上 ②OFF-JT（通常業務と区別した研修）③職務関連（DX化等）**。
  本カリキュラムは業務事例を扱うため③に適合しますが、**業種別応用を組み込むと職務関連性がより明確**になります。

> ⚠️ 助成金の助成率・限度額・要件は年度により変わります。実施前に必ず山口労働局・ハローワークおよび最新パンフレットで確認してください。証憑（出席簿・受講記録・成果物）の管理は `講師運営ガイド.md` を参照。
