# 講師運営ガイド

研修を実際に運営する講師向けの手引き。AI未経験者を相手にする前提で、進行・準備・つまずき対処・
助成金の証憑管理をまとめています。

## 1. 標準タイムテーブル（1回60分）

| 時間 | 内容 | ポイント |
|------|------|---------|
| 0–5分 | 前回の振り返り／今日のゴール | 「今日できるようになること」を1つだけ宣言 |
| 5–20分 | テーマ解説（デモ中心） | 講師が画面を映して**実演**。座学は短く |
| 20–50分 | ハンズオン演習 | 各自が触る。講師＋サポートが**巡回** |
| 50–58分 | 成果の共有・質疑 | 1〜2名に発表してもらう |
| 58–60分 | まとめ・宿題（任意）・次回予告 | 「できた」を必ず言語化して終える |

## 2. 事前準備チェックリスト

**環境**
- [ ] 受講者分のAIツールのアカウント（ログイン情報）を用意
- [ ] Wi-Fi／ネット接続を事前テスト
- [ ] プロジェクタ or 画面共有の動作確認
- [ ] 予備端末（ログイン不調に備える）

**教材**
- [ ] 当日のワークシート（成果物用紙）を人数分
- [ ] プロンプト「魔法の型」カード（第3回で配布、以降も参照）
- [ ] ログイン手順書（第1〜2回で配布）
- [ ] OK/NGクイズ用紙（第9回）

**運営**
- [ ] 出席簿（署名欄・日付・時間）
- [ ] 開始・終了時刻の記録方法（証憑用）
- [ ] サポート役の割り当て（受講者6名につき1名を目安）

## 3. AI未経験者を教えるときのコツ

1. **「間違えても壊れない」を最初に伝える**。触ることへの恐怖を取る。
2. **専門用語を使わない／使うなら言い換える**（プロンプト＝お願いの文、など）。
3. **1回1つだけ**。詰め込むと離脱する。
4. **講師が先にやって見せる → 一緒にやる → 一人でやる**の順（模倣から自立へ）。
5. **できた瞬間を拾って褒める**。小さな成功体験を積ませる。
6. **画面の場所を具体的に指す**（「右下の紙飛行機ボタン」など）。
7. **ゆっくり・待つ**。入力が遅い受講者を急かさない。

## 4. よくあるつまずきと対処

| つまずき | 対処 |
|---------|------|
| ログインできない | 手順書＋予備端末。開始前に全員ログイン完了を確認 |
| 何を入力していいか固まる | 「魔法の型」カードの穴埋めから始めさせる |
| 答えが長すぎる／難しい | 「小学生にも分かるように」「3行で」と追加指示する練習に転換 |
| AIの嘘を信じてしまう | 第6回を強調。「数字・固有名詞・法律は必ず確認」を繰り返す |
| タイピングが遅い | 音声入力やスマホ利用も可と案内。無理させない |
| 「自分の仕事には使えない」と感じる | 第10回の棚卸しで具体化。身近な1業務に絞って成功体験を作る |

## 5. 宿題（任意）の例

強制はしないが、定着のために軽い宿題を推奨。
- 第4回後：「今週出すメールを1通、AIで下書きしてみる」
- 第6回後：「気になることを1つ調べさせて、正しいか確認してみる」
- 第10回後：「棚卸しマップを職場で1つ実際に試す」

## 6. 助成金の証憑管理（重要）

人材開発支援助成金の支給申請では、**訓練を実施した事実と内容**を記録として残す必要があります。
（※必要書類・様式は年度・制度により異なります。最新は山口労働局・ハローワーク／提携社労士に確認）

**毎回そろえる**
- [ ] **出席簿**：受講者氏名・日付・開始/終了時刻・署名。10時間以上の積み上げが分かるように
- [ ] **実施記録**：当日のテーマ・内容（本カリキュラムの該当回を明記）
- [ ] **成果物**：各回のワークシート（受講者が作成したもの）を回収・保管

**コース全体**
- [ ] カリキュラム表（本教材）と実施日程の対応
- [ ] OFF-JT（通常業務と区別）である旨が分かる運営（時間・場所を業務と分ける）
- [ ] 修了時の習得度チェックシート

**注意**
- 出席・時間の**水増しや虚偽記載は不正受給**にあたり、絶対に行わない。
- eラーニング・通信・定額制で行う部分は**賃金助成の対象外**（集合OFF-JTと区別して記録）。
- 実施前に、訓練計画の事前届出が必要（`internal-docs/02_助成金申請サポートマニュアル.md` を参照）。

## 7. 研修から導入・保守へのつなぎ

- 第10回「業務棚卸し＆AI活用マップ」と第11回「エージェント化提案シート」は、
  そのまま**AIエージェント導入フェーズのインプット**になります。
- 研修中は**押し売りをしない**。「こんなこともできる」の提示に留め、希望者に導入・保守を案内。
- 導入後は月額保守で**追加研修・改善**を継続（次年度の助成金再活用も視野に）。
