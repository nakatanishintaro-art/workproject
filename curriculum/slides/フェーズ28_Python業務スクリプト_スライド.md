### S04　用語ミニ講座①「スクリプト・自動化・ライブラリ」
- **スクリプト**：やりたい作業の手順を書いた**小さなプログラム**（1本のファイル）
- **自動化**：手作業でくり返していることを、プログラムに**代わりにやらせる**こと
- **ライブラリ**：よく使う機能を**まとめた道具箱**。呼び出すだけで使える（例：Excelを扱う道具箱）
> 🎤 例え：スクリプト＝「作業マニュアルを機械が読める形で書いたもの」。ライブラリ＝「用意された便利な道具」を借りる感覚。

### S05　用語ミニ講座②「エラー・実行・パス」
- **実行**：スクリプトを**動かす**こと（走らせる）。実行して初めて作業が行われる
- **エラー**：うまく動かないときにPythonが出す**メッセージ**。故障ではなく「ここで困った」の連絡
- **パス**：ファイルやフォルダの**住所**（場所を表す文字列）。どこのファイルを扱うか、を示す
> 🎤 講師ノート：「エラー＝叱られている」ではなく「困りごとの報告」。今日はエラーと仲良くなるのが裏テーマ。

### S06　技術の基礎（ざっくり）：自動化に向く作業とは
- 自動化が**得意**：同じ手順のくり返し、たくさんのファイル、決まったルールの整理・変換・集計
- 自動化が**苦手／不向き**：毎回判断が変わる、例外だらけ、対象が数個だけ（手作業の方が速い）
- コツ：**「同じことを何度も」やっている作業**を見つける＝そこが自動化の狙い目
> 🎤 「手が疲れる・時間がかかる・間違えやすい」くり返し作業ほど、自動化の効果が大きい。

### S17　本編③：デモ（売上表を月別に集計）
🖥 AIへの頼み方（例）：
- 「sales.xlsx を読み込んで、『月』ごとに『金額』を合計し、結果を画面に表示するPythonを書いて。pandasを使ってやさしく」
🖥 コード（例・短く）：
```python
import pandas as pd                      # 表計算の道具箱

df = pd.read_excel("sales.xlsx")         # Excelを読む
result = df.groupby("月")["金額"].sum()  # 月ごとに金額を合計
print(result)                            # 結果を表示
```
> 🎤 3行で集計が終わる驚きを見せる。「1行ずつ何をしているか」をコメントで確認。

### S19　追加：エラーの読み方の初歩
- エラーは**下の方（最後の行）**に「何が困ったか」が書いてある
- よく出る例：`FileNotFoundError`＝ファイルが見つからない（パス／名前の確認）、`ModuleNotFoundError`＝道具箱が入っていない（インストールが必要）
- 対処の近道：**エラー全文をコピーしてAIに貼り、「これはどういう意味？どう直す？」と聞く**
> 🎤 「エラー＝失敗ではなく、直すヒント」。読めなくてもAIに丸ごと見せれば教えてくれる。

### S20　やってみよう：わざとエラーを出して直す（ミニ演習）

### S21　よくある失敗と対処
- ファイルが見つからない → **パス（場所）とファイル名**を確認。フォルダを開き直す
- 道具箱がない（ModuleNotFound）→ **インストールが必要**。エラーごとAIに相談し手順を聞く
- 動くけど結果が変 → **列名・条件**が意図とズレていないか、AIにコードを説明させて確認
- 元ファイルを壊した → だから**コピーで練習**。元データは触らない
> 🎤 「うまくいかない＝故障ではない」。エラーごとコピペしてAIに聞く、が最短ルート。

### S22　安全・情報管理の注意（最重要）

- 演習は**サンプル・架空データ**で。本番の実データやファイルは使わない
- スクリプトは**まずコピーしたファイルで試す**（移動・削除・上書きは元に戻せない）
- AIに貼るコードやデータにも、機密・個人情報を含めない
> 🎤 講師ノート：ここは必ず持ち帰ってもらう。「コピーで練習」「機密は入れない」「認証情報は書かない」の3点。
