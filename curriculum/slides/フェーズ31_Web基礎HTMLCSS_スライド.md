### S04　用語ミニ講座①「HTML・タグ・要素」
- **HTML（エイチティーエムエル）**：Webページの**骨組み**を書くための言葉。中身は“ただの文字ファイル”
- **タグ**：`<p>` のような目印。「ここからここまでが段落ですよ」と印をつける
- **要素**：開始タグ〜終了タグで囲んだ**ひとかたまり**（例：`<p>こんにちは</p>` で1つの段落）
> 🎤 例え：タグは「付箋」。文章のあちこちに「これは見出し」「これは段落」と付箋を貼っていくイメージ。難しくありません。

### S05　用語ミニ講座②「CSS・ブラウザ・属性」
- **CSS（シーエスエス）**：ページの**見た目**（色・大きさ・配置）を決める言葉
- **ブラウザ**：HTMLとCSSを読んで、**画面にきれいに表示してくれる**ソフト（Chrome、Edge など）
- **属性（ぞくせい）**：タグに付ける追加情報。例：リンク先を表す `href`、画像の場所を表す `src`
> 🎤 講師ノート：「HTML＝中身、CSS＝見た目、ブラウザ＝表示係」。この3語だけ今日持ち帰ってもらえれば十分です。

### S06　技術の基礎（ざっくり）
- Webページは、**HTML（骨組み）**と**CSS（見た目）**という2つの文字ファイルでできている
- 家に例えると：**HTML＝柱や壁の骨組み**、**CSS＝壁紙や塗装の内装**
- ブラウザがこの2つを読んで、私たちが見る画面に**組み立てて表示**する
- だから最初は「骨組み（HTML）」から作り、あとで「見た目（CSS）」を足すのが自然な順番
> 🎤 「まず骨組み、あとで飾り付け」。この順番を体で覚えると、あとがラクになります。

### S10　本編①：HTMLで骨組みを作る（解説）
- HTMLは、**文章に「これは何か」の印（タグ）を付ける**だけ
- よく使う5つの部品：**見出し／段落／リスト／画像／リンク**
- まずはこの5つが書ければ、1枚のページの中身は作れる
- 完璧な文法より、「**印を付ける感覚**」をつかむのが今日の目標
> 🎤 むずかしい要素はあとで。まず「見出し・段落・リスト・画像・リンク」の5つだけに集中してもらう。

### S11　本編①：デモ（HTMLの5つの部品）
🖥 短いHTMLの例（そのまま試す）：
```html
<h1>山口 太郎</h1>
<p>建設会社で働いています。よろしくお願いします。</p>
<ul>
  <li>安全第一</li>
  <li>チームワーク</li>
</ul>
<img src="photo.jpg" alt="私の写真">
<a href="https://example.com">会社のサイト</a>
```
- `<h1>`＝大見出し、`<p>`＝段落、`<ul><li>`＝箇条書き、`<img>`＝画像、`<a>`＝リンク
> 🎤 1行ずつ「これは見出し」「これは段落」と声に出しながら、保存→ブラウザ更新で表示を見せる。

### S13　本編②：CSSで見た目を整える（解説）
- 骨組み（HTML）ができたら、**CSS**で**色・大きさ・配置**を足す
- CSSは「**どの部品を、どう飾るか**」を書く：例「見出しは青色」「文字は少し大きく」
- HTMLの `<head>` から `style.css` を読み込めば、見た目がまとめて変わる
- 見た目を変えても**中身（文章）は消えない**。安心して試せる
> 🎤 「内装の模様替え」の感覚。壁紙を貼り替えても部屋の骨組みは変わらない、と伝える。

### S14　本編②：デモ（CSSで色・大きさ・配置）
🖥 短いCSSの例（`style.css` に書く）：
```css
body {
  font-family: sans-serif;   /* 読みやすい書体 */
  max-width: 600px;          /* 横幅を抑える */
  margin: 40px auto;         /* 中央に寄せる */
}
h1 {
  color: navy;               /* 見出しを紺色に */
}
```
- `color`＝色、`max-width`＝横幅、`margin`＝余白と配置
> 🎤 1つずつ値を変えて保存→更新し、「色が変わった」「中央に寄った」を目の前で体感させる。

### S15　ハンズオン②：見た目を整えよう（20分）

- 課題：S12のページに**色を1つ・横幅・余白**を付けて、読みやすくする
- 成果物：**見た目が整った自己紹介ページ**（色や配置が変わったことが分かればOK）
> ⚠️ 色や数字は正解が1つではありません。**いろいろ試して**、好みを見つけるのが上達のコツ。

### S16　本編③：AIに雛形を作らせて改造する（解説）
- ゼロから全部書かなくてよい。**AIに「雛形（ひな形）」を作らせて、そこを直す**のが今どきの作り方
- コツ：**何のページか・入れたい項目・雰囲気**を具体的に伝える
- 出てきたコードは**そのまま使わず**、意味を聞きながら少しずつ自分好みに改造する
- 分からない部分は「**この行は何をしていますか？**」とAIに聞けば説明してくれる
> 🎤 「AIは物知りな新人さん。下書きは任せて、確かめて直すのは自分」。中級で学んだ距離感はここでも同じ。

### S21　よくある失敗と対処
- 表示が変わらない → **保存し忘れ**か**ブラウザ更新忘れ**。「保存→更新」をもう一度
- 画像が出ない → `src` の**ファイル名・場所**が違う。同じフォルダに置いたか確認
- CSSが効かない → HTMLに `style.css` の**読み込み1行**があるか確認／`{ }` の閉じ忘れ
- AIのコードが動かない → **エラー文をそのままAIに貼って**「直して」と頼む
> 🎤 「うまくいかない＝故障ではない」。原因はたいてい“ちょっとした抜け”。落ち着いて1つずつ。
