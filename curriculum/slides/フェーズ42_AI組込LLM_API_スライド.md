### S04　用語ミニ講座①「API・エンドポイント・リクエスト／レスポンス」
- **API**：プログラム同士の“受付窓口”。決まった形でお願いすると、決まった形で答えが返る
- **エンドポイント**：その窓口の住所（呼び出し先のURL）
- **リクエスト**：こちらから送るお願い（プロンプトや設定を入れて送信）
- **レスポンス**：返ってくる答え（AIが作った文章などが入っている）
> 🎤 例え：自動販売機。「お金＋ボタン（リクエスト）」を入れると「商品（レスポンス）」が出る。中の仕組みは知らなくても、使い方さえ守れば動く。

### S05　用語ミニ講座②「トークン・課金・レート制限・環境変数」
- **トークン**：AIが文章を扱う最小単位（単語のかけら）。**入力＋出力の量で料金が決まる**
- **トークン課金**：使った分だけ後払い。長い入力・長い出力ほど高くなる
- **レート制限**：短時間に送りすぎると一時的に断られる仕組み（連打しないための制約）
- **環境変数**：APIキーなどの秘密を、コードの外側に置いておく入れ物
> 🎤 「トークン＝メーター」「レート制限＝並んで待つ」のイメージ。料金と制限は最初に押さえると事故が減る。

### S06　技術の基礎（ざっくり）：呼び出しの流れ
- ①アプリが **プロンプト＋設定** をリクエストにまとめる
- ②APIに送る（**キーで本人確認**）→ AIが処理
- ③**レスポンス**が返る（本文＋使ったトークン数などの情報）
- ④アプリが本文を取り出して **画面に表示**（必要なら保存）
- ⑤失敗したら **エラーを受け取り**、やり直し・メッセージ表示
> 🖥 「入力→送信→受信→表示」の1枚図。上級で学んだ“外部APIを使う（フェーズ34）”の応用だと橋渡し。

### S07　今日使うツール：LLMのAPIとAIペアプロ
- **LLMのAPI**：Claude API（Anthropic）などのチャット系API。プロンプトを送り、文章の応答を受け取る
- **公式SDK**：各言語向けの“便利部品”。少ない行数で呼べる（Python等）
- **AIペアプロ**：Claude Code／Codexにコードを書かせ・直させ・説明させながら進める
- **検証用キー**：本研修では**配布キー**で。料金・上限は講師が管理
> ⚠️ **モデル名・料金・使える機能・呼び出し方は変わります。最新仕様は必ず公式ドキュメントで確認**。今日の値・記述は目安です。

### S08　基本操作①：APIキーを安全に置く（環境変数）
- ①APIキーは**発行元の管理画面**で取得（本研修は配布キー）
- ②**コードに直書きしない**。プロジェクト直下の `.env` に置く
  - 例：`ANTHROPIC_API_KEY=（配布されたキー）`
- ③`.env` は **`.gitignore`** に入れ、GitHubに上げない
- ④コードからは「環境変数を読む」形で使う（キーの実物はコードに出さない）
🖥 画面：`.env`／`.gitignore` の2ファイルを見せ、キーが**コードに現れない**ことを確認
> ⚠️ 最重要：**APIキーを直書きしない・共有しない・リポジトリに上げない**。漏れたら即無効化して再発行。

### S09　基本操作②：最初の1回を呼ぶ（最小コード）
- キーを環境変数から読み、短いプロンプトを1回だけ送って、応答を表示する
🖥 例（Python・イメージ／最新の書き方は公式で確認）：
```python
import os
from anthropic import Anthropic

client = Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])  # キーは環境変数から

msg = client.messages.create(
    model="（公式で最新のモデル名を確認）",
    max_tokens=200,                      # 出力の上限＝料金の上限にもなる
    messages=[{"role": "user", "content": "こんにちは。一言で自己紹介して。"}],
)
print(msg.content[0].text)               # 応答本文を取り出して表示
```
> 🎤 「まずこの1回が通れば、あとは中身（プロンプト）を差し替えるだけ」。詰まったらAIペアプロにエラーを貼って直させる。

### S20　ミニ演習：エラーとレート制限に備える（10分）
- やること：AIペアプロに頼み、**呼び出しを `try`〜`except` で囲む**／失敗時は画面に「時間をおいて再試行してください」を出す
🖥 例（イメージ）：
```python
try:
    msg = client.messages.create(...)
    result = msg.content[0].text
except Exception as e:
    result = "AI応答に失敗しました。少し待って再試行してください。"
    print("エラー内容（開発者用）:", e)
```
> 🎤 「本番は失敗する前提」。落ちない・優しいメッセージ・開発者にはログ、の3点を押さえる。

### S21　よくある失敗と対処
- **401などの認証エラー** → キーの環境変数名・値を確認（配布キーの入れ間違い）
- **キーが読めない** → `.env`の場所／読み込み処理を確認。AIペアプロにエラーを貼る
- **429（レート制限）** → 連打しない。少し待って再試行（S20）
- **応答が長すぎ／途切れる** → `max_tokens`とプロンプトで長さを制御
- **想定外の返答** → プロンプトで形式を固定（「ラベルだけ」「3行で」）
> 🎤 「エラーは会話のきっかけ」。文面をそのままAIに貼れば、たいてい原因を教えてくれる。

### S22　安全・情報管理の注意（最重要）
