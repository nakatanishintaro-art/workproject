### S04　用語ミニ講座①「プログラム・ロジック・コード」

### S10　本編①：条件分岐（if）とは（解説）
- **もし〜なら、この処理をする**、という枝分かれ（分岐）
- 使う記号：`==`（等しい）、`>`（より大きい）、`<`（より小さい）、`>=` / `<=`
- 「そうでなければ」は **`else`**、「別の条件なら」は **`elif`**
- **インデント（行頭の字下げ）**で「if の中身」を表す（Pythonの大事なルール）
> 🎤 例え：改札と同じ。「切符が有効なら通す／そうでなければ止める」。条件で通る道が変わる。

### S13　本編②：繰り返し（for / while）とは（解説）
- **`for`**：決めた回数や、リストの要素ぶん繰り返す（回数がはっきりしているとき）
- **`while`**：条件が成り立つあいだ、ずっと繰り返す（終わりが条件で決まるとき）
- `range(5)` は「0,1,2,3,4」の5回ぶん、という意味
- こちらも **インデント（字下げ）** で「繰り返す中身」を表す
> 🎤 例え：`for`＝「10回スクワット」（回数が決まっている）／`while`＝「日が暮れるまで作業」（条件で終わる）。

### S14　本編②：デモ（for / while を動かす）
🖥 例（そのまま試す）：
```python
# for：5回くりかえす
for i in range(5):
    print("繰り返し", i)

# while：3になるまで足す
count = 0
while count < 3:
    print("カウント", count)
    count = count + 1
```
- `range(5)` の数字を変えて回数が変わることを確認
> ⚠️ `while` は条件がずっと成り立つと**終わらなくなる（無限ループ）**。止めるときはターミナルで `Ctrl + C`。`count = count + 1` を忘れない。

- 課題：`for` で「1番の商品」〜「5番の商品」と5行表示する
- 発展：`for` の中に `if` を入れ、「3の倍数のときだけ★を付ける」に挑戦
- 成果物：**繰り返しの小プログラム**（画面確認 ✔）

### S16　本編③：関数（処理をまとめる）とは（解説）
- **関数**＝よく使う処理に名前をつけた“部品”。1度作れば何度も呼べる
- `def 名前():` で作り、行頭を字下げして中身を書く
- 呼び出しは `名前()`。値を渡す“入り口”が**引数（ひきすう）**、結果を返すのが **`return`**
- メリット：**同じ処理を書き直さなくてよい／直すのは1か所だけ**
> 🎤 例え：電子レンジの「あたためボタン」。中の仕組みを毎回考えず、ボタン（関数）を押すだけで使える。

### S21　よくある失敗と対処
- **インデント（字下げ）ずれ** → `if`/`for`/`def` の中身は同じ幅で字下げ。エラー文をAIに貼る
- **`:`（コロン）忘れ** → `if`・`for`・`while`・`def` の行末に `:` が必要
- **`==` と `=` の取り違え** → 比較は `==`、代入（箱に入れる）は `=`
- **無限ループ** → `while` の終了条件と、値を進める行（`count = count + 1`）を確認。止めるのは `Ctrl + C`
> 🎤 「エラー＝故障ではない」。エラー文は“ヒント”。読めなければAICにそのまま聞く、を徹底。
