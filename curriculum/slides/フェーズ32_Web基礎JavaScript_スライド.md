### S04　用語ミニ講座①「JavaScript・イベント」
- **JavaScript（ジャバスクリプト・JS）**：Webページに**動き**をつけるための言葉（プログラミング言語）
- **イベント**：ページの上で起きる“できごと”。例＝ボタンが**押された**、文字が**入力された**
- JSは「イベントが起きたら、○○する」という書き方が基本
- ※JavaとJavaScriptは**名前が似ているだけの別物**。今日はJavaScriptです
> 🎤 例え：JSは「押したら音が鳴るスイッチ」の配線係。“押されたら”という合図（イベント）に、動きを結びつける。

### S05　用語ミニ講座②「変数・関数・DOM」
- **変数**：数字や文字を**一時的に入れておく箱**。例＝入力された名前を箱にしまう
- **関数**：「まとめて実行する手順のかたまり」。例＝“計算する”手順に名前をつけて呼び出す
- **DOM（ドム）**：ブラウザが理解している**ページの部品の一覧**。JSはこれを通して文字やボタンを操作する
- 今日は言葉を「聞いたことがある→なんとなく分かる」でOK。使いながら覚えます
> 🎤 講師ノート：3語とも今は暗記不要。「箱・手順・部品一覧」のイメージだけ。あとでコードで実物を見せる。

### S06　技術の基礎（ざっくり）：骨・見た目・動き
- Webページは3つの言葉の役割分担でできている
  - **HTML**＝ページの**骨組み**（見出し・ボタン・入力欄などの部品）
  - **CSS**＝**見た目**（色・大きさ・配置）
  - **JavaScript**＝**動き**（押したら反応・入力を受け取る・表示を変える）
- 前フェーズで「骨と見た目」を作った。今日はそこに「動き」を足すだけ
> 🎤 「家に例えると、HTMLが柱、CSSが内装、JSがスイッチや自動ドア」。役割が違うだけで、こわくない。

### S10　本編①：解説「ボタンを押すと反応する」
- JSでいちばん基本の動き＝「**ボタンが押されたら、○○する**」
- 手順は3つ
  - ①動かしたい部品（ボタン）を**名前（id）**で見つける
  - ②その部品に「**押されたら**」という合図（イベント）を結びつける
  - ③押されたときに**やること**を書く
- この「見つける→合図をつける→やることを書く」は、あらゆる動きの土台
> 🎤 「今日出てくる動きは、ほぼ全部この3ステップの応用。ここだけ体でつかめば十分」。

### S11　本編①：デモ「押したらメッセージが出る」
🖥 画面例（サンプル・そのまま試せる）：
```html
<button id="btn">押してね</button>
<p id="msg"></p>

<script>
  const btn = document.getElementById("btn");
  btn.addEventListener("click", function () {
    document.getElementById("msg").textContent = "ボタンが押されました！";
  });
</script>
```
- `getElementById`＝id で部品を**見つける**／`addEventListener("click", …)`＝**押されたら**の合図／`textContent`＝**表示の文字を変える**
> 🎤 一行ずつ「これは何をしている？」をAIに説明させながら読む。丸暗記ではなく“意味が分かる”を目指す。

### S13　本編②：解説「入力欄の文字を受け取る」
- 次の動き＝「**入力欄に打った文字を、JSで受け取る**」
- ポイントは1つ：入力欄（`<input>`）の中身は **`.value`** で取り出せる
- 受け取った文字は**変数（箱）**にしまって、そのまま表示に使える
- 「入力を受け取る→加工する→表示する」が、便利な機能の基本の流れ
> 🎤 「フォームに名前を書いてもらって、あいさつ文を作る…みたいなことができる。`.value`が入口」。

### S14　本編②：デモ「名前を入れたらあいさつする」
🖥 画面例（サンプル）：
```html
<input id="name" placeholder="お名前">
<button id="hello">あいさつ</button>
<p id="out"></p>

<script>
  document.getElementById("hello").addEventListener("click", function () {
    const name = document.getElementById("name").value;
    document.getElementById("out").textContent = name + "さん、こんにちは！";
  });
</script>
```
- `.value`で入力欄の文字を取り出し、`+`で文をつなげて表示している
> 🎤 空欄のまま押すとどうなる？も一緒に試す。「こうしたい」はAIに追加で頼めばよい、と体感させる。

### S15　ハンズオン②：入力を受け取ってみよう（20分）
- 手順：①`<input>`とボタンを足す→②AIに「入力した文字を受け取って表示するJS」を頼む→③試す→④「○○さん、こんにちは」のように文を足してみる
- 課題：**入力した内容が画面に表示される**ようにする
- 成果物：**動作メモ**に「入力→表示ができた」と記録＋気づいたことを一言
> 🎤 講師ノート：`.value`だけ覚えれば十分。文字をつなぐ`+`は「くっつける記号」と説明。

### S16　本編③：解説「計算して表示を変える」
- 3つ目の動き＝「**受け取った値を計算して、結果を表示する**」
- 注意：入力欄の中身は**文字あつかい**。数字として計算するには **`Number(…)`** で数に変える
- 「入力を受け取る→計算する→結果を表示する」で、**簡易計算**ができる
- 表示の切り替え（例：チェックの数を数える）も、同じ「表示を変える」の応用
> 🎤 「1＋1が“11”になったら、それは文字のまま足したサイン。`Number`で数に変える、が今日の小さなコツ」。

### S17　本編③：デモ「2つの数を足す簡易計算」
🖥 画面例（サンプル）：
```html
<input id="a" type="number"> ＋ <input id="b" type="number">
<button id="calc">計算</button>
<p id="answer"></p>

<script>
  document.getElementById("calc").addEventListener("click", function () {
    const a = Number(document.getElementById("a").value);
    const b = Number(document.getElementById("b").value);
    document.getElementById("answer").textContent = "答えは " + (a + b);
  });
</script>
```
- `Number(...)`で数に変換→`a + b`で計算→`textContent`で結果を表示
> 🎤 「足し算ができたら、`+`を`*`にすれば掛け算。AIに『掛け算に変えて』と頼むだけ」と応用の広がりを見せる。

### S18　ハンズオン③：簡易計算を作ろう（20分）

- 課題：**2つの数を入れてボタンを押すと、答えが出る**ページにする
- 成果物：**動作メモ**に「計算→表示ができた」と記録＋試した計算の種類を一言
> ⚠️ 数として計算するときは`Number`で変換、を忘れずに。うまくいかない時はConsole（S09）を見る。

### S19　追加テーマ：AIに「書かせて・読んで・直す」

### S21　よくある失敗と対処
- **動かない** → まずF12→Console（S09）を見る。赤いエラー文をAIに貼って原因を聞く
- **ボタンを押しても無反応** → idの綴りがHTMLとJSでずれていないか確認（大文字小文字も一致）
- **計算がおかしい（1+1が11）** → `Number(...)`で数に変換したか確認
- **`<script>`の場所** → 本文の一番下（`</body>`直前）に置くと安定
> 🎤 「エラーは“故障”ではなく“メッセージ”。読んでAIに聞けば、たいてい直せる」。
