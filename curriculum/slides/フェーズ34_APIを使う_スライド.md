### S04　用語ミニ講座①「API・リクエスト・レスポンス」
- **API**：あるサービスの機能やデータを、外のプログラムから使うための**窓口（約束事）**
- **リクエスト**：こちらから送る「これをください」という**お願い**
- **レスポンス**：向こうから返ってくる**答え（データ）**
- **エンドポイント**：お願いを送る**あて先のURL**
> 🎤 例え：レストランの注文。**メニュー＝API**、**注文＝リクエスト**、**料理＝レスポンス**、**注文カウンター＝エンドポイント**。厨房の中身を知らなくても、決まった頼み方をすれば料理が出てくる。

### S05　用語ミニ講座②「JSON・APIキー・ステータスコード」
- **JSON（ジェイソン）**：データをやり取りするための**書式**。`{ }`と`" "`で「名前：値」を並べた形。プログラムで扱いやすい
- **APIキー**：サービスを使う人を見分ける**合鍵（パスワードのようなもの）**。持ち主以外に渡してはいけない
- **ステータスコード**：通信の結果を表す番号。**200＝成功**、**404＝見つからない**、**500＝相手側の不具合**
> 🎤 講師ノート：JSONは今日いちばん触る言葉。「住所録のような、名前と値のセット」とだけ押さえればOK。細かい記法は触りながら慣れる。

### S09　基本操作②：はじめての1回（呼んで、結果を見る）
- いちばん短い形。まず**呼べること**を体験する
```python
import requests

# 郵便番号から住所を返す公開API（キー不要）
url = "https://zipcloud.ibsnet.co.jp/api/search"
res = requests.get(url, params={"zipcode": "7530814"})  # 山口県庁周辺の例
```

### S10　本編①：リクエストとレスポンス（解説）

- まず`res.status_code`を見て、**200かどうか**で成功／失敗を判断する
> 🎤 「注文（params）を付けて送ると、番号（成功か）と料理（データ）が返る」。S04のレストランの例えに戻して結びつける。

### S16　本編③：APIキーの安全な扱い＋エラー処理（解説）
- **APIキーが要るAPI**もある（今日の演習は不要なものを使用）。キーは**合鍵＝絶対に公開しない**
- ⚠️ やってはいけない：**コードに直書き**して共有・GitHubに上げる・画面共有で映す
- 安全なやり方：キーは**環境変数**に入れ、コードからは`os.environ`で読む（コード本体にキーを書かない）
- 通信は失敗することがある（圏外・相手の不調・打ち間違い）。**エラー処理**で止まらないようにする
> 🎤 講師ノート：ここが今日の最重要。キー漏洩は実害（不正利用・課金）につながる。「直書きしない・公開しない・機密は送らない」を強く。

### S17　本編③：デモ（安全なキーの読み方＋エラー処理）
🖥 キーは環境変数から読む（例。今日のサンプルAPIでは実際には不要）：
```python
import os, requests

api_key = os.environ.get("MY_API_KEY")  # コードに直書きしない

url = "https://zipcloud.ibsnet.co.jp/api/search"
try:
    res = requests.get(url, params={"zipcode": "7530814"}, timeout=10)
    res.raise_for_status()          # 200以外なら例外にする
    data = res.json()
    print(data["results"][0]["address1"])
except requests.exceptions.RequestException as e:
    print("通信に失敗しました：", e)  # 止まらずメッセージを出す
```
> ⚠️ `try / except`で「失敗しても落ちない」。`timeout`で「返ってこないとき待ち続けない」。

### S20　追加ツールの基本操作・ミニ演習（保存してみる）
🖥 取り出した住所を1行、CSVに書き出す：
```python
import csv, requests

res = requests.get("https://zipcloud.ibsnet.co.jp/api/search",
                   params={"zipcode": "7530814"}, timeout=10)
r = res.json()["results"][0]

with open("address.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["都道府県", "市区町村", "町域"])
    writer.writerow([r["address1"], r["address2"], r["address3"]])

print("address.csv に保存しました")
```
> 🖥 生成された`address.csv`をExcel／VS Codeで開いて中身を確認する。

### S21　よくある失敗と対処
- `ModuleNotFoundError: requests` → `pip install requests`を実行し忘れ。入れてから再実行
- ステータスが`200`以外 → URL・params・郵便番号の打ち間違いを確認（404＝あて先/対象なし、500＝相手側）
- `KeyError` → JSONに無い名前を指定している。まず`print(data)`で実際の名前を確認
- ずっと返ってこない → `timeout`を付ける／ネットワークを確認
- 文字化け → 保存時に`encoding="utf-8"`を付ける
> 🎤 「エラー文は敵ではなく道案内」。そのままAIに貼れば直し方が返ってくる、を繰り返し伝える。
