# 研修スライド一式（4段階・全48フェーズ × 各30枚）

フェーズ制カリキュラム（1フェーズ＝3時間）の**講義スライド下書き**。各フェーズ30枚・全48フェーズ＝**計1,440枚**。
Markdownの「スライド1枚＝1見出し（### SXX）」形式で、実際のスライド化（PowerPoint／Googleスライド／Canva／Gamma／NotebookLM 等）の元原稿として使えます。各デッキ巻末に「画像案（ショットリスト）」つき。

## まず読むもの
- **`00_共通仕様とツールロードマップ.md`** … 30枚テンプレート、AIツール導入ロードマップ、用語集、制作ルール。
- 設計の全体像は `../48フェーズ_4段階カリキュラム設計.md`（タイトル・内容・料金・助成金）。

## 到達目標（4段階）
- **初級（1–12）**：ChatGPTとMicrosoft Copilotをしっかり使える。
- **中級（13–24）**：ノーコード＋自動化で業務ツールを自作できる。
- **上級（25–36）**：プログラミングの基礎をAI支援で習得し、小さなWebアプリを作れる。
- **エキスパート（37–48）**：業務アプリを本格構築・AI組込・公開・運用できる（＝AI活用で作れる初級エンジニアの入口／内製化人材）。

## スライド化のヒント
- 各 `### SXX` を1枚に。箇条書きが本文、`🎤`は発表者ノート、`🖥`はデモで見せる画面/入力例、`⚠️`は注意喚起。
- **Gamma／Copilot in PowerPoint／NotebookLM** にこのMarkdownを渡すと、下書きから素早くスライド化できます。巻末の画像案を画像生成に使えます。

## 注意
- 各ツールの画面・機能・料金・商用可否は変化が速いため、スライドには「**最新仕様は各公式サイトで確認**」を明記しています。
- 演習はすべて**サンプル題材**で、個人情報・機密・APIキーは入れない前提です（本番の実データ運用・実装は導入/保守フェーズで）。
- 上級・エキスパートは**AIペアプロ（Claude Code／Codex）前提**で、未経験者でも「読める・直せる・作れる」を段階的に獲得する構成です。到達像は誇張せず「初級エンジニアの入口／内製化人材」に統一。
