# 研修スライド一式（12フェーズ × 各30枚）

フェーズ制カリキュラム（1フェーズ＝3時間）の**講義スライド下書き**。各フェーズ30枚・全12フェーズ＝**計360枚**。
Markdownの「スライド1枚＝1見出し（### SXX）」形式で、実際のスライド化（PowerPoint／Googleスライド／Canva／Gamma 等）の元原稿として使えます。

## まず読むもの
- **`00_共通仕様とツールロードマップ.md`** … 30枚テンプレート、AIツール導入ロードマップ、マスター用語集、制作ルール。**全フェーズ共通の設計図**。

## 各デッキの30枚テンプレート（共通）

## スライド化のヒント
- 各 `### SXX` を1枚に。箇条書きが本文、`🎤`は発表者ノート、`🖥`はデモで見せる画面/入力例、`⚠️`は注意喚起。
- **Gamma** や **Copilot in PowerPoint** にこのMarkdownを渡すと、下書きから素早くスライド化できます（フェーズ6で扱う手法）。

## 注意
- 各ツールの画面・機能・料金・商用可否は変化が速いため、スライドには「**最新仕様は各公式サイトで確認**」を明記しています。実施前に最新情報で更新してください。
- 演習はすべて**サンプル題材**で行い、個人情報・機密は入れない前提です（本番の実データ運用は導入・保守フェーズで）。
- 助成金の証憑として、各フェーズの**成果物**（S26総合演習・S27チェック）を保管してください（`../講師運営ガイド.md`）。
