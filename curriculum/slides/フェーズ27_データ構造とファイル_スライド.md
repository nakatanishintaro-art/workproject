### S04　用語ミニ講座①「リスト・辞書・データ構造」
- **リスト**：ものを**順番に並べた入れ物**。例）買い物メモ「りんご・みかん・ばなな」。前から0番目、1番目…と番号で取り出す
- **辞書**：**名前（キー）で値を取り出す入れ物**。例）名簿「名前→山田／部署→営業」。番号ではなく“見出し”で引く
- **データ構造**：データを**どう並べて持つかの型**。用途に合った入れ物を選ぶと、扱いがぐっと楽になる
> 🎤 例え：リストは「行列に並んだ人」、辞書は「名前で引ける電話帳」。同じ“入れ物”でも、探し方が違います。

### S05　用語ミニ講座②「CSV・データフレーム・pandas」
- **CSV**：カンマ区切りの**シンプルな表データ**（`.csv`）。Excelでも開ける、軽くて交換しやすい形式
- **データフレーム**：プログラムの中で表を扱うための**表そのもの**（行と列のかたまり）というイメージ
- **pandas（パンダス）**：Pythonで**表データを読み書き・集計**するための定番の道具（ライブラリ）。表計算をプログラムでやる相棒
> 🎤 「Excelのシートを、そのままプログラムの中に持ち込むのがデータフレーム」。pandasはそれを扱う道具箱、と伝える。

### S06　技術の基礎（ざっくり）
- プログラムでデータを扱うとは、**「入れ物に入れて → 取り出して → 加工して → 保存する」**の繰り返し

- 大量の行でも**手順は一度書けば同じ**。100行でも1万行でも、同じコードで一気に処理できるのが強み

### S10　本編①：リストと辞書（解説）
- **リスト**：`[ ]`で囲み、`,`で区切って**順番に**入れる。番号（0から）で取り出す
- **辞書**：`{ }`で囲み、`"名前": 値`の形で入れる。**名前**で取り出す
- 使い分け：**並び順で扱いたい→リスト**／**見出しで引きたい→辞書**
- この2つは、表データを扱うときの土台になる考え方
> 🎤 「表の1行＝辞書（列名→値）、その行が何行も並んだもの＝リスト」。あとで出てくる表データの正体がこれ、と予告する。

### S11　本編①：デモ（リストと辞書）
🖥 コード例（短く・やさしく）：
```python
# リスト＝ものを順番に並べた入れ物
kudamono = ["りんご", "みかん", "ばなな"]
print(kudamono[0])        # → りんご（0番目）
kudamono.append("かき")   # 末尾に「かき」を追加

# 辞書＝「名前」で値を取り出す入れ物
shain = {"名前": "山田", "部署": "営業", "年齢": 30}
print(shain["部署"])      # → 営業
```
> 🎤 `[0]`で番号取り出し、`["部署"]`で名前取り出し。取り出し方の違いを指さしで確認する。

### S17　本編③：デモ（集計→書き出し）
🖥 コード例：
```python
import pandas as pd

df = pd.read_csv("uriage_sample.csv")

# 「商品」ごとに「金額」を合計する
shukei = df.groupby("商品")["金額"].sum()
print(shukei)

# 集計結果を新しいCSVに書き出して保存する
shukei.to_csv("shukei_kekka.csv")
```
🖥 実行 → 集計がターミナルに出て、フォルダに`shukei_kekka.csv`ができるまで実演
> 🎤 `groupby("商品")`＝商品でまとめる、`["金額"].sum()`＝金額を合計、`to_csv`＝書き出す。3つの部品を指さしで確認。
