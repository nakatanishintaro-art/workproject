# 山口県AI・DX人材育成センター 事業計画書

> **一言でいうと**
> 「人材開発支援助成金（事業展開等リスキリング支援コース）」を資金エンジンにして、
> **AI研修 → 現場AIエージェント導入 → 月額保守** を、山口県の中小企業（建設・製造・サービス）へ
> **ワンストップかつ低自己負担**で提供する事業モデル。
> 助成金で「学ぶハードル」を下げて入口を作り、導入と保守（MRR）で継続収益を積み上げる。

*本書は2025〜2026年度想定のドラフト。助成率・限度額・要件は年度ごとに改定されるため、実施前に必ず山口労働局・ハローワークおよび最新パンフレットで確認すること（本書の数値は掲載パンフレット LL080408 に基づく）。*

|------|------|

| ターゲット | 山口県内の中小企業（雇用保険適用事業所）— 建設業／製造業／サービス業 |

## 1. 事業機会：なぜ「今」「山口県」で成立するか

### 1-1. 追い風
- **国の政策資金**：人材開発支援助成金 事業展開等リスキリング支援コースは、DX・新規事業向け訓練に対し中小企業で**経費の75%**を助成。AI導入が対象要件（DX化）に明確に合致する。
- **地方の人材・IT格差**：都市部と比べ山口県の中小企業はAI/DX着手が遅れており、「何から始めるか分からない」層が厚い＝伴走型の需要が大きい。
- **AIエージェントの実用化**：生成AIが「問い合わせ対応・書類作成・記録整理」など中小の定型業務に直接効く段階に入り、投資回収が説明しやすくなった。

### 1-2. 中小企業の本音の障壁と、本モデルの解
| 障壁 | よくある声 | 本モデルの解 |
|------|-----------|-------------|
| コスト不安 | 「研修も導入もお金がかかる」 | 助成金で自己負担を圧縮、費用対効果を数値提示 |
| 使いこなせない不安 | 「入れても現場が使わない」 | 研修で人を育ててから導入＝定着率が上がる |
| 何を頼めばいいか不明 | 「相談先が分からない」 | 診断→研修→導入→保守をワンストップ |
| 手続きの煩雑さ | 「助成金申請が面倒」 | 提携社労士＋書類テンプレで申請負担を軽減 |

## 2. ターゲットと業種別ユースケース

**共通条件**：雇用保険適用事業所であること（＝ほぼ全ての法人が対象）。個人事業でも雇用保険加入者がいれば可。

| 業種 | 現場の痛み | 導入するAIエージェント例 | 研修テーマ |
|------|-----------|------------------------|-----------|
| **建設業** | 写真整理・報告書・安全書類・積算に時間 | 現場写真自動仕分け／日報・報告書ドラフト生成／安全書類チェック／過去見積からの積算補助 | 生成AI基礎＋建設事務効率化＋プロンプト設計 |
| **製造業** | 検査記録・生産日報・マニュアル属人化 | 日報→集計自動化／作業マニュアルAI検索／不良報告の要約・分類 | AIによる記録・分析基礎＋多能工化支援 |
| **サービス業** | 予約・問い合わせ・口コミ対応の人手不足 | 問い合わせ一次対応チャット／予約整理／口コミ返信ドラフト／シフト調整補助 | 接客×AI活用＋業務自動化基礎 |

## 3. サービス設計：ワンストップの4ステップ

```
[STEP1] 無料AI・DX診断         … 業務棚卸し・課題抽出・助成金該当性の判定
   │      （リード獲得・信頼構築のフック）
   ▼
[STEP2] 助成金申請支援 + 研修設計 … 訓練実施計画・事業展開等実施計画の作成支援（社労士連携）
   │      「職業訓練実施計画届」＋「事業展開等実施計画（様式第1-3号）」
   ▼
[STEP3] AI・DXリスキリング研修   … OFF-JT 10時間以上／職務関連・DX要件に適合
   │      （＝助成対象。ここで人材を育成）
   ▼
[STEP4] AIエージェント導入 + 月額保守 … 現場実装（初期構築費）＋継続改善・追加研修（MRR）
```

- **STEP1・2が入口の設計**：診断を無料〜低額にして母数を増やし、助成金という「実質割引」で研修への心理的ハードルを下げる。
- **STEP4が収益の本体**：研修で終わらせず、育てた人材が使うツールまで納品するから導入率が高く、保守が継続する。

## 4. 助成金の仕組み（設計の前提）

**事業展開等リスキリング支援コース／中小企業（通常分）**

| 区分 | 内容 |
|------|------|
| 経費助成 | **75%**（大企業60%） |
| 賃金助成 | **1人1時間 1,000円**（大企業500円）※eラーニング・通信・定額制は対象外 |
| 経費助成限度額（1人あたり） | 10h以上100h未満＝**30万円** ／ 100h以上200h未満＝**40万円** ／ 200h以上＝**50万円** |
| 設備投資加算 | 経費助成に**+50%**（賃金/資格手当要件＋事業展開等促進機器の導入が条件）。上限：1人15万円、10人以上は総額150万円 |
| eラーニング・通信 | 経費助成のみ（中小15万円上限）、賃金助成なし |
| 定額制サービス | 経費助成のみ、受講者1人1月あたり2万円上限 |
| 1事業所の年度上限 | **1億円** |

**訓練の必須要件**：①10時間以上 ②OFF-JT ③職務関連かつ「事業展開／DX化・GX化／人材育成計画」のいずれかに該当。

> ⚠️ **重要な法的注意**：助成金の**申請代行は社会保険労務士の独占業務**。センターが無資格で代行すると違法。
> → **提携社労士**と組み、センターは「研修提供＋計画書作成の支援・助言」に徹する設計とする。

## 5. ユニットエコノミクス（試算モデル）

### 5-1. モデルケース：建設業・中小企業／受講者5名／集合研修100時間

| 項目 | 金額 | 備考 |
|------|------|------|
| 研修受注額（税抜） | 40万円 × 5名 = **200万円** | 100h以上200h未満の経費助成上限に合わせて設計 |
| 経費助成（顧客が受給） | 30万円 × 5名 = **150万円** | 40万円×75%＝30万円（1人あたり上限内） |
| 賃金助成（顧客が受給） | 1,000円 × 100h × 5名 = **50万円** | 訓練中の人件費を補填 |
| **顧客の実質自己負担** | 200万 − 150万（経費助成） = **50万円** | さらに賃金助成50万で実質ほぼ相殺 |

> ポイント：顧客から見ると「200万円の研修が、助成金で実質数十万円〜ほぼ相殺」。この訴求力が入口を強くする。
> （※助成金は後払い・要件充足が前提。顧客は一旦立替が必要な点は正直に説明する。）

### 5-2. 1社あたり生涯収益（LTV）イメージ

| 収益源 | 単価 | 回数/期間 | 小計 |
|--------|------|-----------|------|
| ① 研修（助成金活用） | 200万円 | 初年度1回 | 200万円 |
| ② AIエージェント導入（初期構築） | 50〜150万円 | 1回 | 100万円（中央値） |
| ③ 月額保守 | 5〜15万円/月 | 24ヶ月（想定継続） | 240万円（10万×24） |
| ④ 追加研修（2年目以降・再度助成金活用） | 100万円 | 任意 | 100万円 |
| **合計（LTV目安）** | | | **約600万円/社** |

**MRRが事業の背骨**：研修・導入は一過性だが、月額保守が積み上がると売上が安定し評価も上がる。「保守契約数」を最重要KPIに置く。

### 5-3. 設備投資加算の活用
研修に加えて「事業展開等促進機器（業務用PC・タブレット・現場端末等）」を導入し、賃金/資格手当要件を満たせば経費助成に**+50%**（1人15万円・10人以上で総額150万円上限）。ハードを絡めた導入提案で助成額をさらに引き上げられる。

## 8. Go-to-Market（集客・営業）

1. **公的機関との連携**：山口県商工会議所・商工会・よろず支援拠点・金融機関と組み、「助成金活用AI・DXセミナー」を共催（信頼と集客を同時に獲得）。
2. **無料診断をフックに**：セミナー参加者へ無料AI・DX診断→助成金該当性提示→研修提案の導線。
3. **業種別の成功事例づくり**：建設・製造・サービス各1社の初期導入をショーケース化し、同業への横展開（地方は口コミ・紹介が強い）。
4. **社労士・ITベンダー・会計事務所との紹介網**：申請支援は社労士、記帳・投資は会計事務所と相互送客。
5. **自治体DX施策との接続**：山口県／各市のDX補助・デジタル化支援と併用提案。

## 9. オペレーション体制

| 機能 | 担い手 | 備考 |
|------|--------|------|
| 研修設計・講師 | センター（自社＋外部講師） | カリキュラム標準化で品質担保 |
| 助成金申請 | **提携社労士** | 独占業務。センターは書類作成支援・計画設計に限定 |
| AIエージェント構築 | センター開発チーム | テンプレ化して構築コスト低減 |
| 月額保守・改善 | センターサポート | 問い合わせ・プロンプト改善・追加学習 |
| 営業・診断 | センター＋提携先 | 商工会議所等と連携 |

**標準化がスケールの鍵**：業種別の研修テンプレ・エージェントテンプレ・申請書類ひな形を整備し、1社ごとの構築工数を圧縮する。

## 10. リスクと対策

| リスク | 内容 | 対策 |
|--------|------|------|
| 法令（独占業務） | 助成金申請代行は社労士の独占業務 | 提携社労士とアライアンス、契約で役割分担を明確化 |
| 制度改定 | 助成率・限度額・要件が年度で変わる | 労働局と情報連携、パンフ改定を都度反映、顧客契約に「制度変更条項」 |
| 不支給リスク | 要件不充足で助成金が下りない | 事前該当性チェックを徹底、「助成金は保証しない」旨を明示、研修自体の価値で納得を得る |
| 立替負担 | 助成金は後払い | 立替期間を明示、金融機関のつなぎ融資紹介 |
| 品質・定着 | 研修しても現場が使わない | 導入＋保守で伴走、KPIモニタリング、追加研修 |
| 属人化 | 講師・エンジニア依存 | カリキュラム・テンプレの標準化、外部講師プール |

## 12. まとめ：この事業モデルの勝ち筋

1. **助成金＝入口の摩擦をなくす装置**：「実質ほぼ無料でAI人材を育成」という強い訴求で商談数を増やす。
2. **研修で終わらせない**：育てた人材が使うAIエージェントまで納品するから、成果が出て導入率が上がる。
3. **保守（MRR）で稼ぐ**：一過性の研修・導入ではなく、継続保守で安定収益と顧客関係を築く。
4. **地域密着×業種特化**：山口県の建設・製造・サービスに絞り、事例横展開と紹介で効率的に拡大。
5. **法令順守を設計に内蔵**：社労士連携で独占業務リスクを回避し、持続可能な体制にする。

> 研修は「入口」、AIエージェント導入は「価値の証明」、月額保守は「収益の土台」。
> 助成金でこの3層を回すのが、山口県AI・DX人材育成センターの事業設計です。
