# 集客用WEBサイト（ランディングページ）

山口県AI・DX人材育成センターの集客用LP。`index.html` 1ファイルで完結（外部依存なし・CSS/JS/画像すべてインライン）。そのままブラウザで開けます。

## 特徴
- **CV最適化**：ヒーロー→共感→ワンストップ4ステップ→助成金ビフォーアフター→業種別タブ→差別化→モデルケース→料金→不安Q&A→フォームの王道導線。CTAを反復配置。
- **トンマナ**：藍（信頼）×柿色（行動喚起）を基調に、山口・地域密着＋先進性を両立。ライト/ダーク両対応。
- **レスポンシブ**：スマホ最下部に固定CTAバー。SP/PCで最適表示。
- **アクセシビリティ**：フォーカスリング、`prefers-reduced-motion` 対応、代替テキスト付きSVG。
- **法令配慮**：助成金は「保証しない」明記、公的機関でない旨・提携社労士による申請の旨を明示、実績は「モデルケース」と明記。

## 公開前に差し替える箇所（プレースホルダ）
| 箇所 | 現在の値 | 差し替え先 |
|------|---------|-----------|
| 電話番号 | `0120-000-000` | 実際の受付番号（ヘッダー・CTA・フッター・`tel:` リンク） |
| フォーム送信先 | `mailto:info@example.com` | 実際の受信メール、または問い合わせフォームのPOST先（`<script>` 内 `mail` 変数） |
| 会社情報・所在地 | 未記載（サンプル） | 正式名称・所在地・営業時間 |
| フォーム注記 | 「掲載用サンプル」の一文 | 公開時は削除 |
| 免責事項（フッター） | 一般的記載 | 自社の正式表記・特定商取引法等に合わせて調整 |

## 公開方法
- **静的ホスティング**：`index.html` をそのままアップロードするだけ（Netlify / Vercel / GitHub Pages / レンタルサーバ等）。
- **フォーム連携**：バックエンドが無い場合は、Googleフォーム/フォームサービス/フォームメール（PHP等）に接続してください。現状はデモとして `mailto:` を起動します。

助成率・限度額・要件は年度改定されます。数値の記載は掲載時点の一般情報のため、公開前に最新のパンフレット・山口労働局／ハローワークの情報でご確認ください。
