# 02 助成金申請サポートマニュアル

> 対象：助成金サポート担当／営業／研修チーム。人材開発支援助成金（事業展開等リスキリング支援コース）の申請を、**社労士と役割分担しながら**顧客が確実に受給できるよう伴走するための手引き。
> **最重要：申請代行は社会保険労務士の独占業務。センターは「計画書作成の支援・助言」と「証憑整備の伴走」に徹し、申請書類の作成代行・提出・労働局折衝は必ず提携社労士が行う。**
> **助成率・限度額・要件・様式は年度改定される。各案件で必ず山口労働局・ハローワークの最新情報と社労士確認を優先する。**

---

## 1. 申請の全体フローと標準スケジュール

事業展開等リスキリング支援コースは **「計画届の事前提出 → 訓練実施 → 支給申請」** の順。**訓練開始前**の計画届提出が絶対条件。

```
[T-2ヶ月〜] 事前準備・該当性確認（センター＋社労士）
      │  事業展開等の実態確認、訓練計画の設計、対象者の確定
      ▼
[訓練開始日の一定期間前まで] ★計画届の提出（社労士が提出）
      │  「職業訓練実施計画届」＋「事業展開等実施計画（様式第1-3号）」等
      │  ※提出期限は制度で定められている（訓練開始前）。必ず労働局で最新期限を確認
      ▼
[訓練実施] OFF-JT 10時間以上を計画どおり実施（研修チーム）
      │  出席簿・受講記録・成果物・費用の証憑を確実に整備（03参照）
      ▼
[訓練終了後の一定期間内] 支給申請（社労士が提出）
      │  支給申請書＋賃金・経費の証憑一式
      ▼
[審査 → 支給決定 → 入金（後払い）]
```

> ⚠️ **期限は制度で厳格に定められている**（計画届＝訓練開始前、支給申請＝訓練終了後の所定期間内）。**具体的な日数は年度・様式で変わるため、案件ごとに社労士・労働局で必ず確認**し、逆算スケジュールを組む。営業段階から研修開始日を早めに固める。

## 2. 必要書類一覧（代表例）

> 様式番号・要否は年度改定される。**最新の様式・必要書類は必ず社労士／労働局のパンフレット・様式集で確認**。以下は代表例。

### 2-1. 計画届段階（訓練開始前）
- [ ] 職業訓練実施計画届
- [ ] 事業展開等実施計画（様式第1-3号 等）… 事業展開／DX化・GX化／人材育成計画の内容を記載
- [ ] 訓練別の対象者一覧・カリキュラム（時間割・科目・OFF-JTである旨）
- [ ] 訓練委託契約書（案）・見積書（センターの研修）
- [ ] 事業展開等の実態を示す書類（新事業・DX化の根拠資料 等）
- [ ] 事業所の雇用保険適用を示す書類

### 2-2. 訓練実施中に整備する証憑（03と連動）
- [ ] 出席簿（受講者・日付・時間・署名）
- [ ] 受講記録・タイムテーブル実績
- [ ] 成果物・受講レポート等
- [ ] 講師・カリキュラムの実施記録

### 2-3. 支給申請段階（訓練終了後）
- [ ] 支給申請書（様式一式）
- [ ] 訓練実施の証憑（上記出席簿等）
- [ ] 経費の証憑（請求書・領収書・振込記録）
- [ ] 賃金助成の根拠（賃金台帳・出勤簿・労働条件）
- [ ] （設備投資加算を使う場合）機器導入の証憑・賃金/資格手当要件の根拠

## 3. 社労士との役割分担（境界の正）

| 工程 | センター（研修事業者としての支援・助言） | 提携社労士（独占業務・専門判断） |
|------|------------------------------------------|----------------------------------|
| 該当性判断 | 一次的な見込みの整理、材料集め | **最終的な受給可否・要件充足の判断** |
| 計画書作成 | 訓練カリキュラム・研修内容の設計、記載内容の**素材提供・下書き支援・助言** | **申請書類としての作成・完成・提出**、労働局との折衝 |
| 訓練実施 | OFF-JT研修の実施、証憑の作成・整備 | 証憑の適法性チェック・助言 |
| 支給申請 | 経費・実施の証憑を揃えて社労士へ提供 | **支給申請書の作成・提出**、審査対応 |
| 顧客説明 | 事業・研修内容・スケジュールの説明 | 助成金制度・要件・リスクの専門的説明の補完 |

### 境界を越えないためのルール
- センターは**「申請を代行する」と言わない・書かない・やらない**。
- 申請書類の**最終作成・押印・提出は社労士**。センターは素材提供・下書き支援まで。
- 判断に迷う要件は**必ず社労士に確認**してから顧客へ回答する。
- 顧客・社労士・センターの三者で**役割分担を契約書に明記**する。

## 4. 該当性チェックリスト（社労士確認前の整理用）

**基本要件**
- [ ] 雇用保険適用事業所である
- [ ] 訓練が **10時間以上**
- [ ] 訓練が **OFF-JT**（通常業務から離れて実施）
- [ ] 訓練が **職務に関連** している
- [ ] 訓練が「**事業展開／DX化・GX化／人材育成計画**」のいずれかに該当（＝AI・DX研修は該当しやすいが実態が必要）
- [ ] 訓練開始前に**計画届を提出できる**スケジュール
- [ ] 対象者が支給対象となる被保険者である
- [ ] 過去に不正受給等の**欠格事由がない**

**金額設計（中小・通常分／年度改定あり・要確認）**
- [ ] 経費助成 **75%** を前提に受注額を設計
- [ ] 経費助成限度額（1人）：10-100h＝**30万円**／100-200h＝**40万円**／200h以上＝**50万円**
- [ ] 賃金助成 **1人1時間1,000円**（eラーニング・通信・定額制は**対象外**）
- [ ] 設備投資加算 **+50%**（賃金/資格手当要件＋事業展開等促進機器導入が条件、1人15万円・10人以上で総額150万円上限）を使うか
- [ ] 1事業所の**年度上限1億円**の範囲内か
- [ ] eラーニング：経費助成のみ（中小15万円上限）／定額制：経費助成のみ（1人1月2万円上限）

> このチェックはあくまで整理用。**Yes/Noの最終確定は社労士・労働局**。

## 5. 顧客への説明義務（必ず実施・記録を残す）

受注前・契約時に以下を**口頭＋書面**で説明し、理解を得る。説明した記録を残す。

- [ ] **助成金は後払い（立替が必要）**：研修費等は一旦顧客が支払い、支給決定後に助成金が入金される。立替期間が生じる。必要に応じて金融機関のつなぎ融資を紹介。
- [ ] **不支給リスク**：要件を満たさない・審査で認められない場合、助成金は下りない。「助成金は保証しない」ことを明示。
- [ ] **要件充足が前提**：訓練の実態、出席、証憑が揃わないと支給されない。顧客側の協力（対象者の出席等）が必要。
- [ ] **制度改定**：助成率・限度額・要件は年度で変わり得る。契約に制度変更条項を入れる。
- [ ] **申請主体**：申請は顧客が行い、代行するのは社労士であること。センターは研修提供と計画書作成支援。

> ❌ 禁止：「必ず受給できる」「確実に○○万円戻る」等の断定。→ 不正・トラブルの元。

## 6. 標準スケジュール逆算テンプレート（案件管理用）

| マイルストーン | 目安 | 担当 | チェック |
|----------------|------|------|----------|
| 該当性の一次確認 | 訓練開始 T-2ヶ月頃 | 営業＋助成金サポート | 診断シート・一次チェック |
| 社労士へ相談・要件確定 | T-6〜8週 | 助成金サポート→社労士 | 受給可否の見立て |
| 計画届・実施計画の作成支援 | T-5〜6週 | センター（支援）＋社労士（完成） | 様式最新確認 |
| **計画届 提出** | 訓練開始前の所定期限まで | **社労士** | 期限厳守・受理確認 |
| 訓練実施・証憑整備 | 訓練期間中 | 研修チーム | 出席簿等（03） |
| 支給申請 | 訓練終了後の所定期間内 | **社労士** | 証憑一式 |
| 支給決定・入金 | 審査後 | ― | 入金確認・保管継続 |

> 具体的な「所定期限／所定期間」の日数は**年度・様式により異なる**。案件ごとに社労士・労働局で確定して埋める。

---

## 7. 不正受給の絶対禁止（再掲・厳守）
- 架空研修、出席の水増し、証憑の改ざん、費用の水増し、対象外（eラーニング等）を賃金助成対象と偽る等は**絶対禁止**。
- 不正受給は返還＋加算金＋事業所名公表＋刑事罰、センターの信用失墜につながる。少しでも疑義があれば社労士・責任者に相談する。

---

## 8. 証憑の保管
- 助成金関連の証憑は、**支給決定後も労働局が定める期間、確実に保管**する（顧客・センター双方で管理方針を合意）。詳細な証憑リストは「03_研修運営マニュアル.md」を参照。
