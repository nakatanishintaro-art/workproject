# 内部運用ドキュメント 索引（山口県AI・DX人材育成センター）

本ディレクトリは、山口県AI・DX人材育成センターの**社内向け運用資料**をまとめたものです。
上位方針は事業計画書 `../business-plan/山口県AI・DX人材育成センター_事業計画.md` にあり、本資料群はその数値・用語・方針に従います。

> ⚠️ **共通の重要注意**
> - 助成率・限度額・要件・様式は**年度ごとに改定**されます。実施前に必ず**山口労働局・ハローワークの最新情報**と**提携社労士**で確認してください。
> - **助成金の申請代行は社会保険労務士の独占業務**です。センターは「研修提供＋計画書作成の支援・助言」に徹し、申請代行は行いません。
> - **助成金は保証しません**（後払い・要件充足が前提）。不正受給は絶対禁止です。
