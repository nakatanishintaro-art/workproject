## 1. 事業の目的と提供価値

- **一言でいうと**：国の「人材開発支援助成金（事業展開等リスキリング支援コース）」を資金エンジンに、**AI研修 → 現場AIエージェント導入 → 月額保守** をワンストップで提供する。
- **ターゲット**：山口県内の中小企業（雇用保険適用事業所）— 建設業／製造業／サービス業。
- **収益3層**：
  1. 研修（助成金活用） … 入口。実質自己負担を圧縮して母数を作る。
  2. AIエージェント導入（初期構築費） … 価値の証明。
  3. 月額保守（MRR） … 収益の土台。**最重要KPI = 月額保守契約数**。
- **勝ち筋**：助成金で入口の摩擦をなくし、育てた人材が使うツールまで納品し、保守で継続収益を積む。

## 2. 組織体制と役割分担（RACI）

| 機能 | 主担当 | 概要 | 社労士との関係 |
|------|--------|------|----------------|
| 営業・診断 | 営業チーム | リード獲得、AI・DX診断、提案、受注、料金/助成金シミュレーション | 該当性の一次判断まで。最終判断は社労士に確認 |
| 助成金サポート | 助成金サポート担当（営業と兼務可） | 計画書作成の**支援・助言**、証憑管理の伴走、社労士との窓口 | **申請代行は行わない**。書類の最終確認・提出は社労士 |
| 研修（設計・講師） | 研修チーム（自社＋外部講師） | カリキュラム設計、講師手配、OFF-JT実施、証憑作成 | 訓練要件（10h/OFF-JT/職務関連）を満たす設計で連携 |
| 開発（導入） | 開発チーム | AIエージェント要件定義〜構築〜納品 | ― |
| 保守 | サポートチーム | 月額保守、問い合わせ対応、改善、アップセル起点 | ― |
| 提携社労士 | 外部（アライアンス） | **助成金申請代行（独占業務）**、要件の最終判断、労働局対応 | 契約で役割分担を明文化 |

### 役割分担の原則（最重要・違法回避）
- 助成金の**申請代行は社会保険労務士の独占業務**（社会保険労務士法）。センターが無資格で代行すると違法。
- センターの提供範囲は **「研修提供 ＋ 計画書作成の支援・助言 ＋ 証憑整備の伴走」** に限定する。
- **申請書類の作成代行・提出代行・労働局との折衝は必ず提携社労士が行う**。境界は「02_助成金申請サポートマニュアル.md」の役割分担表を正とする。

## 3. 業務フロー全体像（4ステップ）

```
[STEP1] 無料AI・DX診断         … 業務棚卸し・課題抽出・助成金該当性の一次判定
   │      （リード獲得・信頼構築のフック）担当：営業
   ▼
[STEP2] 助成金申請支援 + 研修設計 … 訓練実施計画・事業展開等実施計画の作成"支援"
   │      「職業訓練実施計画届」＋「事業展開等実施計画（様式第1-3号）」
   │      担当：助成金サポート＋研修／最終確認・提出：提携社労士
   │      ★訓練開始前に計画届を提出（後述の期限厳守）
   ▼
[STEP3] AI・DXリスキリング研修   … OFF-JT 10時間以上／職務関連・DX要件に適合
   │      担当：研修チーム／証憑（出席簿・受講記録・成果物）を確実に整備
   ▼
[STEP4] AIエージェント導入 + 月額保守 … 現場実装（初期構築費）＋継続改善・追加研修（MRR）
          担当：開発→サポート
```

- STEP1・2は**入口の設計**（診断を無料〜低額に、助成金で心理的ハードルを下げる）。
- STEP4が**収益の本体**（保守MRR）。研修で終わらせない。

## 4. KPI管理

### 4-1. 主要KPI
| KPI | 定義 | 目標感（事業計画準拠） | 管理頻度 |
|-----|------|----------------------|----------|
| **月額保守契約数（最重要）** | 有効な月額保守契約の件数 | 1年目6件 → 2年目20件 → 3年目40件 | 月次 |
| MRR | 月額保守の月次経常収益 | 保守単価10万円/月を基準に積み上げ | 月次 |
| 研修→導入 転換率 | 研修受注社のうち導入に進んだ割合 | 高いほど良い（要モニタリング） | 四半期 |
| 診断→研修 転換率 | 無料診断から研修受注に至った割合 | ― | 月次 |
| 研修導入社数（累計） | 研修を実施した社数 | 1年目10社 → 2年目30社 → 3年目60社 | 月次 |
| 想定年商 | 研修・導入 ＋ 保守MRR年換算 | 約2,400万 → 約6,800万 → 約1.3億円 | 四半期 |

### 4-2. 補助KPI
- リード数、初回商談数、無料診断実施数、提案書提出数、成約率、保守解約率（チャーン）、顧客満足度（CS）、追加研修（2年目再助成）提案数。

### 4-3. 運用ルール
- 数値は**月次レビュー**で確認。MRRとチャーンは毎月必ず確認する。
- 目標未達の場合は「診断→研修」「研修→導入」のどのファネルが弱いかを分解して対策する。

## 5. コンプライアンス（絶対遵守）

### 5-1. 社労士独占業務（最重要）
- 助成金の**申請代行・提出代行はセンターでは行わない**。必ず提携社労士が担う。
- センターの表現は「研修提供」「計画書作成の**支援・助言**」に統一。営業資料・契約書・トークで「申請を代行します」「弊社が手続きします」と言わない・書かない。
- 疑わしいときは必ず提携社労士に確認してから進める。

### 5-2. 助成金不正受給の絶対禁止
- 以下は**厳禁**（不正受給は返還＋加算金＋事業所名公表＋刑事罰の対象、センターの信用も失墜）：
  - 実施していない訓練を実施したことにする（架空研修）。
  - 出席していない受講者を出席扱いにする、出席簿・受講記録の改ざん。
  - 訓練時間・費用の水増し。
  - 賃金助成対象外（eラーニング・通信・定額制）を対象として申請させる。
- **「助成金が下りる」と保証・断定しない**。要件不充足で不支給になり得ること、後払い・立替が必要なことを必ず顧客に説明する（説明義務。詳細は02・03参照）。

### 5-3. 個人情報・機密情報保護
- 顧客の従業員情報（氏名・雇用保険・賃金等）、業務データを扱う。個人情報保護法を遵守。
- 取得目的の範囲でのみ利用、第三者提供は同意ベース、提携社労士への提供も契約・同意に基づく。
- 詳細な取扱いは第6章のセキュリティ方針に従う。

### 5-4. 誇大・虚偽表示の禁止
- 実績のない事例を「導入実績」として掲げない。効果は根拠のある範囲で示す。
- 「必ず○○万円もらえる」等の断定表現を禁止（禁止トークは01参照）。

## 6. 情報管理・セキュリティ方針

### 6-1. データ分類
| 区分 | 例 | 取扱い |
|------|----|--------|
| 機密（個人情報含む） | 従業員名簿、賃金台帳、雇用保険情報、診断シートの回答 | アクセス制限、暗号化保管、最小権限、持ち出し禁止 |
| 社外秘 | 顧客の業務データ、見積、契約、社内マニュアル | 権限者のみ、共有は必要範囲 |
| 公開可 | 会社案内、公開セミナー資料 | 制限なし |

### 6-2. 運用ルール
- **アクセス権限は最小権限の原則**。役割に応じて付与し、退職・異動時に速やかに剥奪。
- 顧客データはクラウド上の**アクセス制御された共有ストレージ**で一元管理。ローカル端末への恒久保存・USB等での持ち出しは原則禁止。
- パスワードは強固に、多要素認証を有効化。共有アカウントは避ける。
- **生成AI／外部AIサービスに顧客の個人情報・機密データを入力しない**（学習・外部送信リスク）。マスキングまたは契約上安全なサービスに限る。導入案件で顧客データを扱う場合は顧客の同意と契約範囲を確認。
- 提携社労士・外部講師・外部ベンダーとは**秘密保持契約（NDA）**を締結。
- インシデント（漏えい・紛失等）発生時は、直ちに責任者へ報告し、影響範囲の特定・顧客への連絡・再発防止を行う。

### 6-3. 証憑・書類の保管
- 助成金関連の証憑（出席簿、受講記録、成果物、領収書、契約等）は、**支給後も定められた期間（労働局の指示に従う。一般に支給決定後一定年数）保管**する。詳細は02・03参照。

## 7. 制度改定への対応
- 助成率・限度額・要件は**年度改定**される。以下を徹底：
  - 全書類・提案資料に「**実施前に山口労働局・ハローワークで最新要件を確認**」の注意書きを入れる。
  - 労働局・社労士と情報連携し、パンフレット改定を都度マニュアルへ反映。
  - 顧客契約に「制度変更条項」を入れる。
- 本書内の数値は事業計画書（LL080408基準）に準拠。改定時は事業計画書とマニュアルを同時更新する。
